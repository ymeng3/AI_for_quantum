++++++++++++++++++++++++++++++++++++++++++++++++++++

RHEED Simulator.cdf is a self-contained file of the program. To run it, Wolfram Mathematica (MMA) is required to be installed. The program was tested with MMA versions >11. 
RHEED Simulator.nb is the source codes. Running the codes will generate a new program interface.
By default, the program starts with a 1×1 squre lattice model. The input can be altered for other simulations. Some example parameters are given in Supplementary Material.pdf. Users can make multiple copies of the .cdf file, in which the simulations can be defined, run and saved independently. 
Manual.pdf is the guide for users.
